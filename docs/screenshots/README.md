# 界面截图 / Screenshots

README 里的界面图目前是**布局示意图**（`docs/ui-layout.svg`）。欢迎把真机截图放这里，会被主 README 引用。

## 想要哪些截图

| 文件名 | 内容 | 建议 |
|--------|------|------|
| `home.png` | 手机端主界面（连接状态 + 播放信息 + 方向五键 + 角落小键） | 竖屏，宽度 ≥ 720px |
| `touchpad.png` | 「更多工具」展开的触摸板 | 可含正在拖动的手指轨迹 |
| `bilibili-nav.png` | B站首页空间导航高亮卡片的样子 | 手机端显示紫色边框即可 |
| `desktop-tray.png` | 电脑端托盘菜单（配对码 / 访问地址） | 可打码配对码 |

## 约定

- PNG 或 WebP，单张 ≤ 500 KB；手机截图用系统原图即可，不必压缩过度；
- 不要在截图里暴露真实配对码 / Token / 本机公网 IP（托盘截图请打码）；
- 加进 README 的写法：

```markdown
| 主界面 | 触摸板 | 空间导航 |
|--------|--------|----------|
| ![主界面](docs/screenshots/home.png) | ![触摸板](docs/screenshots/touchpad.png) | ![空间导航](docs/screenshots/bilibili-nav.png) |
```
